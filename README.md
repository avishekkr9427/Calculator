# Calculator
Calculator is a front-end web application that performs basic arithmetic operations through a simple and user-friendly interface.

Calculator is a front-end web application that performs basic arithmetic operations through a simple and user-friendly interface. The project is designed to simulate the functionality of a real calculator while focusing on clean layout, responsiveness, and accurate calculations.

The application is built using HTML, CSS, and JavaScript. HTML is used to structure the calculator display and buttons, while CSS handles the visual design, alignment, and responsive layout. A grid-based button layout is implemented to maintain consistency and ease of use across different screen sizes.

JavaScript is responsible for the core calculation logic. It processes user input, handles operations such as addition, subtraction, multiplication, and division, and updates the display in real time. Input validation is included to ensure correct results and smooth interaction during continuous calculations.

Attention is given to UI details like spacing, button feedback, and readability to provide a smooth user experience. The code is organized and easy to understand, making the project suitable for beginners and scalable for future enhancements such as keyboard support or advanced operations.

Working on this project improved my understanding of JavaScript logic, event handling, DOM manipulation, and responsive UI design. This Calculator application demonstrates the ability to combine functionality and design to build a practical, real-world web tool using core front-end technologies.
